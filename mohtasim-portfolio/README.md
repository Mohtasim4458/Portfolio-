# Mohtasim Portfolio

A simple four-page personal portfolio made with HTML5 and CSS3 for CSC 337.

## Pages
- `index.html` — Home
- `hobbies.html` — Hobbies and games
- `media.html` — Social-style posts, images and five YouTube embeds
- `contact.html` — Contact details, form and Google Map

## Run locally
Open `index.html` in a web browser.
