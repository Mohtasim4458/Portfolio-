# Mohtasim Portfolio

A simple four-page personal portfolio made with HTML5 and CSS3 for CSC 337.

## Pages
- `index.html` — Home
- `hobbies.html` — Hobbies and games
- `media.html` — Social-style posts, images and five YouTube embeds
- `contact.html` — Contact details, form and Google Map

## Run locally
Open `index.html` in a web browser.

## Before submitting
Replace the sample email, phone number, friend names and student IDs in `contact.html` with your own correct details. Check that the YouTube videos and map load, then validate all four HTML pages and `css/style.css`.
